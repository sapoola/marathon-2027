# Marathon 2027 — training plan

Plan for a first marathon on Sunday 21 February 2027 (Seville, or self-supported around Amsterdam).
Goals:
- A 3:40
- B 3:45
- C 3:55.

| File | What it is |
|---|---|
| `plan.json` | **Source of truth.** Every session, every week, 24 Aug 2026 → 21 Feb 2027. Edit this, nothing else. |
| `render.py` | `python3 render.py` — regenerates the .ics and the HTML calendar from plan.json and recomputes weekly totals. |
| `marathon-2027.ics` | The calendar iCloud subscribes to. Regenerated by render.py. |
| `marathon-2027-calendar.html` | Phone/laptop calendar (served via GitHub Pages). Regenerated by render.py. |
| `calendar_template.html` | Template render.py fills. |
| `ADJUSTMENT-RULES.md` | The rules the Monday routine applies. Deterministic. |
| `PLAN.md` | The written plan — goals, paces, week-by-week, gym, 70.3, race day. |
| `briefs/` | One file per Monday review. |

## Subscribe (iCloud)
    webcal://raw.githubusercontent.com/sapoola/marathon-2027/main/marathon-2027.ics
Mac: Calendar → File → New Calendar Subscription → paste → Location: iCloud, refresh every hour.

## Calendar app
    https://sapoola.github.io/marathon-2027/marathon-2027-calendar.html
Open in Safari on the phone → Share → Add to Home Screen. Always current.

## Weekly routine
A Claude Code cloud Routine runs every Monday 06:00 Europe/Amsterdam: reads last week from Strava, applies `ADJUSTMENT-RULES.md`, edits `plan.json` if a rule fires, runs `render.py`, commits, and writes the brief to `briefs/`. See `ROUTINE-PROMPT.md`.

## Editing by hand
Change a session in `plan.json` (km, title, detail — keep `id`), run `python3 render.py`, commit and push. iCloud picks it up within the hour.
